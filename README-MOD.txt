# Mobs Maneiros

Mod para Minecraft Java 1.20.1 com Forge 47.4.10. Requer Java 17.

## Compilar e instalar

No Windows, abra o Prompt de Comando nesta pasta e execute `gradlew.bat build`. Copie `build/libs/mobsmaneiros-1.0.0.jar` para a pasta `mods` do perfil Forge.

## Invocar com comandos

- `/summon mobsmaneiros:azeite_de_oliva`
- `/summon mobsmaneiros:cachorro`
- `/summon mobsmaneiros:empresario`
- `/summon mobsmaneiros:lento`
- `/summon mobsmaneiros:gogozone`
